# UI 自动化代码风格

- 使用 Python 和 pywinauto。
- pywinauto 默认使用 `backend="uia"`。
- import 放在文件顶部，标准库与第三方库之间空一行。
- 使用中文注释，注释放在对应操作之前。
- 每个测试步骤按照“定位控件 → 等待控件 → 执行操作”的顺序编写。
- 使用 `child_window()` 定位控件。
- 优先使用稳定属性：`auto_id`、`control_type`、`title`。
- 定位条件必须能够唯一识别控件。
- 操作控件前调用 `wait("visible enabled ready")`。
- 点击真实 UI 控件时使用 `click_input()`。
- 参数逗号后加空格，每行尽量只执行一个操作。
- 不要硬编码进程 ID，应用路径、窗口标题和超时时间使用配置管理。
- 测试代码必须包含清晰的中文步骤说明。

示例：

```python
# 定位“导入音乐”按钮
import_button = window.child_window(
    auto_id="play2.addLocal",
    control_type="Button",
)

# 等待按钮可以操作
import_button.wait("visible enabled ready")

# 点击“导入音乐”按钮
import_button.click_input()
